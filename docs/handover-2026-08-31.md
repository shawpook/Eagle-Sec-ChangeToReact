## 1. 任务书与铁律（每步改动前自查）

**任务**：把 Eagle 复刻项目前端在原目录 `src/app` 内原地改造为 **React 19 + TypeScript + Vite**，
逐个子系统替换，直到全部完成才停（用户"继续任务"即授权自动推进，不问确认）。

**三条铁律**：
1. **原版界面像素级一致**：DOM 结构与 class 名和旧版逐字相同，样式直接复用原 CSS/SCSS，禁止凭感觉重写。
2. **功能不改变**：每个按钮/菜单/快捷键/右键/拖拽行为与旧版一致。
3. **数据面零改动**：ipcRenderer 通道名、REST 端点、electron-settings 键、localStorage 键全部原样保留
   （**含原版拼写错误**：`chnage-preferences`、`chnage-shortcut`、`progress.regenerateThumbanil.msg` 等逐字保留）。

**改造方式**：入口始终是 `src/app/index.html`（main.cjs 窗口 URL 不动）；新代码放 `src/app/react/`；
每移植完一个控制器/指令就删掉对应旧引用；Angular 全部删完后移除 angular.min.js。

**每阶段完成标准（不达标不许 commit）**：`npx tsc --noEmit` 零错 → dev 栈可用 → CDP 写闭环断言
（node + websocket 连 Runtime.evaluate 查 DOM，Page.captureScreenshot 留存 test-run/）→ 全量回归
（`node tests/run-react-suite.mjs`）→ `node tests/run-api-smoke-isolated.mjs` 哨兵绿 → git commit。

**测试健康**：断言 angular scope 的旧闭环测试随 React 化改写为 DOM/CDP 断言；过渡期禁止
"React 版已验证 + 旧实现未删"的提交。

**禁止事项**：禁止截图对拍从 0 写（必须读原源码机械转换）；禁止改 `src/app` 以外文件（例外：
index.html/preferences.html 接线、vite 配置 `frontend/vite.preview.config.mjs`、`frontend/public/shims.js`、
`electron/main.cjs` 测试驱动、`tests/` 测试文件、`frontend/public/mock-library` 残渣清理）；禁止删旧文件
直到 React 版验证通过；禁止中途中断等待确认。

## 4. 已验证方法论与教训（跨单元复用，全部写进 PROGRESS）

1. **ngSafe（$exceptionHandler 等价）**：`try { fn(); } catch (e) { console.error(e); }` 包所有
   $watch/$on/ipc/JSX handler 边界——mock 环境 shim stub 会让原版在 Angular 边界抛错被吞；React
   未捕获异常会静默卸载整树（hostHtmlLen→0 是崩树信号）。
2. **hooks 规则**：所有 hooks 必须在 `if (!host) return null` 早退之前。
3. **jQuery stopPropagation 拦截 React 根委托**：元素级监听需 `onMouseDownCapture`（.item 选中语义）。
4. **React setState 同任务异步冲刷**：同一 eval 内 emit+click 会读到 stale DOM（按钮未渲染）→ 冒烟拆 eval。
5. **el.blur() 在 CDP 不触发 React focusout**：测试手发 `new FocusEvent('focusout',{bubbles:true})`。
6. **ng-show 逐字对照**（三次教训）：`ngShow(!x)` 写反会因初始可见掩盖时序 bug；表达式必须逐字。
7. **bundle 顶层 var → window；顶层 const（IPCHelper 等）不在 window**——React 取不到时直接等价
   ipcRenderer.send（webp cancel 教训，7d-6c）。
8. **mock ipc emit 前置空 event 对象**：`callback({}, ...args)` → 组件 handler 签名 `(e, payload)` 与
   真实 Electron 一致；冒烟 emit 只传 payload。
9. **ipc.send spy**：rest 参数已去 channel → 记录 `[...args]`（7d-6b 教训）。
10. **shims DOM poke 依赖**：换壳后 shim 里 query 旧元素（如 close-export-task poke file-export-progress）
    落空静默跳过 → React 版合并语义（7d-6b）。
11. **body scope 桥接**：空 link 指令模板绑定 body scope 属性 → `body.$watch('prop')` 函数型 watcher
    读 length/字段串；取消按钮用 `scopeApply`（ng-click $apply 等价，否则 digest 不跑 watcher 不触发）。
12. **外部 store + 测试契约**：组件暴露 `window.__eagleXxx` getter（DuplicateScanPanel/LibraryLoad/
    preferences entry 先例），冒烟直读。
13. **偶发竞态家族**（重跑即绿，不算回归失败）：main-ui-workflow multi-inspector-persistence、
    react-stage7a cm-overlay-close、react-stage7a cm-keepopen-checked-toggle、video-thumbnail
    startAt（ffmpeg seek）。
